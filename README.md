# hxyfront-62001 船舶轮机值班工作台

面向轮机员的抄表与交接班工作台（React + Vite + TypeScript，纯前端、localStorage 存储）。

## 功能与规则

- **抄表带采样时刻**：主机、1/2 号发电机的转速、滑油压力、冷却水温；采样时刻与录入时刻分离，可改时间补录。
- **看板只信最新未过期值**：每台设备每个参数只取最近一次、未舍弃、未过期的读数；有效期可选 15/30/60 分钟。
- **过期退出趋势并重算状态**：读数超龄后立即退出看板与迷你趋势，设备状态重算为"读数过期"；异常单不因此自动关闭。
- **异常随读数生成/解除**：越上限/下限自动开单（记极值），回到区间自动解除；待核值触发的单据带"待核"标记。
- **交接封版**：把本班全部读数与未结异常固化为摘要；封版后对该班的补录只追加为差异（补录读数、异常的新增/解除），摘要永不变更。
- **断网双份、回网合并**：机舱与驾驶台断网时各存一份本地暂存；回网按"设备 + 参数 + 采样时刻"合并——同值合并来源端，同时刻不同值则两条都保留并挂"待核"，核实后采用一条、另一条留痕舍弃。

## 演示引导

页面内置一班已交接数据（DG2 水温异常快照未结 + 封后补录已回区）和一组机舱/驾驶台同刻异值的待核读数。

1. 顶栏可 **+45 分钟快进**：观察读数过期、退出趋势、设备变"读数过期"。
2. 切换 **断网**，分别选机舱/驾驶台抄同一设备同一时刻的不同值，再联网点 **回网合并**：两条值同屏待核。
3. 待核卡片上点"核实采用"，另一条标记舍弃但留痕。
4. 填交班/接班人后 **封版交接**；把录入时间改到刚封版的班次再抄一条，可见"封后补录差异"而摘要不变。
5. 抄一条超量程的值（如主机冷却水温 90℃），异常时间线自动开单；再抄正常值即解除。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62001；`npm run build` 产出静态包。数据存于浏览器 localStorage，可随时"重置演示"。
